## 关于本项目

“缺演论”尝试从缺口出发，理解欲望、创造、知识生成与文明演化。这个仓库是该理论体系的公共权威版本库，用来发布经过确认的中文与英文文本、电子书和阅读版 PDF，并保存可核验的版本历史。

本项目以文化传播和公共思想建设为目的。完整作品可以在许可范围内免费阅读、下载、复制与传播。
